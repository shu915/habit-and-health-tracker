# 画面の一覧(作ってあるものだけ)

いま実装されている画面を、種類ごとに並べた一覧。UI の変更を Claude Design と決めるときの、渡す元になる。**作っていないもの(メールの文面、期限切れの画面、規約のページなど)は、ここに書かない**(公開前の宿題は `docs/release-checklist.md`)。画面の規則は `docs/screens.md`、グラフは `docs/charts.md`。2026-11-06 時点。

生活習慣の記録アプリ。食事・体重・睡眠・運動・日記を記録し、集計と AI のレポートを見る。日本語の UI。スマホ幅(375px)から使える。色は `globals.css` のトークン(ダークモードは OS の設定に従う)。

## ログイン前
| 画面 | 中身 |
|---|---|
| `/login` | ロゴ、アプリ名(h1)、メールアドレス欄、「ログインリンクを送る」。状態は、初期・送信中・送信後(「メールを送りました」と、届かないときの注記)・回数制限・エラー。ログイン済みなら `/` へ移動する |

## 閲覧の画面
| 画面 | 中身 |
|---|---|
| `/`(ダッシュボード) | ウエストの更新の帯(月末)。1 日の消費カロリーの目安と、プロフィールの要約。AI レポートへのボタン。日付欄と「開く」。記録のカレンダー(1 年。狭い画面は 13 週)。日々の記録の一覧(記録のある日だけ、14 件ずつ、ページ送り)。推移のグラフ(睡眠、体重・体脂肪率、摂取カロリーと目標、摂取 − 消費の差。期間は 7 / 28 / 90 日の切り替え) |
| `/days/[date]`(日の詳細) | 朝の記録、この日の結果、栄養のレーダー、食事の一覧、運動、良かったこと、今日の気づき。前の日・次の日への移動つき(無い側は、押せない表示で同じ場所に残る) |
| `/reports` | AI レポートの作成と一覧。同意(最初の 1 回だけチェック。2 回目から 1 行)、バッジの条件(折りたたみ)、随時レポートの枠(直近 4 週間)、定期レポートの枠(月を選ぶ)、それぞれの作ったレポートの一覧。「作る」を押しても移動せず、枠の中が「作成中」に変わり、できたら一覧が切り替わる |
| `/reports/[id]` | レポートの表示。並びは、バッジ(1 つも無ければ節ごと出さない)→ 総合評価 → 項目ごとのグラフと気づき。作成中(動く帯と経過秒数)と失敗の表示もここ。上と下に戻るボタン |

## フォームの画面
| 画面 | 入力する項目 |
|---|---|
| `/profile/edit` | 性別、年齢、身長、現在の体重・体脂肪率、ウエスト、目標体重・目標カロリー、活動係数。「提案」ボタンで入力欄を埋める。18 歳未満の案内もある |
| `/days/[date]/edit` | 朝の体重、体脂肪率、就寝時刻、起床時刻 |
| `/days/[date]/meals/new` | 写真かテキストで AI が推定し、結果(品目の内訳の表)を確認して保存する。食べた時刻。幅は 3xl(ほかのフォームは 2xl) |
| `/days/[date]/meals/[id]/edit` | 食事の修正と削除(確認つき)。幅は 3xl |
| `/days/[date]/exercises/new` | 運動の種類、強度、時間、開始時刻、メモ |
| `/days/[date]/exercises/[id]/edit` | 運動の修正と削除(確認つき) |
| `/days/[date]/positive` | 良かったこと(1 日 3 件) |
| `/days/[date]/reflection` | 今日の気づき(長文) |

## 共通の枠・部品
- ヘッダー: ロゴ、アプリ名、メールアドレス(`sm` 以上)、ログアウト
- 「戻る」ボタン(グレーの塗り。`w-fit`)。フォームの下のボタンの行(`FormActions`。「キャンセル、決定」の並びで、決定が右。削除は広い画面で左端、狭い画面で下の行)
- ボタンの規則: 決定する操作だけ深い緑(`accent`)、弱い操作はベージュのグレーの塗り(`neutral`)
- 状態の表示: 読み込み中、AI の処理中(食事の推定は動く帯と秒数、レポートの作成は枠の中の小さな輪)、空の状態(記録ゼロ)、エラー(赤は、失敗や入力の誤りだけ)、「まだ記録できません(プロフィールの設定が先)」の誘導
- 注記: 「医療上の指示ではない」、AI への送信の同意文、記録が不完全な日の但し書き
- グラフ 7 種: 体重、体脂肪率、睡眠、摂取カロリー、摂取 − 消費の差、栄養のレーダー、記録のカレンダー

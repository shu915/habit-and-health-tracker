# 画面の一覧(UI デザインの依頼用)

UI を Claude Design と決めるために、画面を洗い出した一覧。デザインが決まったら、実装して、`docs/screens.md`(画面の規則)を直す。2026-11-05 時点。

生活習慣の記録アプリ。食事・体重・睡眠・運動・日記を記録し、集計と AI のレポートを見る。日本語の UI。まず友人数人が使う。スマホ幅(375px)を想定する。

## A. ログイン前
| # | 画面 | 中身 |
|---|---|---|
| A1 | `/login` | アプリ名、見出し、メールアドレス欄、「ログインリンクを送る」。状態は、初期・送信中・送信後(「メールを送りました」と、届かないときの注記)・回数制限(赤字)・エラー(赤字)。ログイン済みなら `/` へ移動する |
| A2 | ログインのメール(**未実装**) | マジックリンクのメールの件名・本文・ボタン。いまは開発用にコンソールへ出すだけ(本番は Resend の予定) |
| A3 | リンクが期限切れ・使用済みのときの画面(**未実装**) | 理由の説明と、もう一度ログインリンクを送る導線。いまは Better Auth の標準の動作に任せている |

## B. 閲覧の画面
| # | 画面 | 中身 |
|---|---|---|
| B1 | `/`(ダッシュボード) | プロフィールの要約。レポートへのボタン。日付欄と「開く」。記録のカレンダー(GitHub の草風、1 年)。日々の記録の一覧(記録のある日だけ、14 件ずつ、ページ送り)。推移のグラフ(睡眠、体重・体脂肪率、摂取カロリーと目標、摂取 − 消費の差。期間は 7 / 28 / 90 日の切り替え) |
| B2 | `/days/[date]`(日の詳細) | 朝の記録、この日の結果、栄養のレーダー、食事の一覧、運動、良かったこと、今日の気づき。前の日・次の日への移動つき |
| B3 | `/profile` | プロフィールの表示(目標値、ウエストの更新の帯を含む) |
| B4 | `/reports` | レポートの一覧(作成中・失敗の表示を含む)と、作成フォーム(同意チェック、随時と定期の枠、月の選択) |
| B5 | `/reports/[id]` | レポートの表示(期間のグラフ、バッジ、AI の講評、注目日付の印)と、作成中の進捗の表示 |

## C. フォームの画面
| # | 画面 | 入力する項目 |
|---|---|---|
| C1 | `/profile/edit` | 性別、年齢、身長、現在の体重・体脂肪率、ウエスト、目標体重・目標カロリー、活動係数。「提案」ボタンで入力欄を埋める。18 歳未満の案内もある |
| C2 | `/days/[date]/edit` | 朝の体重、体脂肪率、就寝時刻、起床時刻 |
| C3 | `/days/[date]/meals/new` | 写真かテキストで AI が推定し、結果(品目の内訳の表)を確認して保存する。食べた時刻 |
| C4 | `/days/[date]/meals/[id]/edit` | 食事の修正と削除(確認つき) |
| C5 | `/days/[date]/exercises/new` | 運動の種類、時間、開始時刻、メモ |
| C6 | `/days/[date]/exercises/[id]/edit` | 運動の修正と削除(確認つき) |
| C7 | `/days/[date]/positive` | 良かったこと(1 日 3 件。できごと + なぜ良かったか) |
| C8 | `/days/[date]/reflection` | 今日の気づき(長文) |

## D. 共通の枠・部品
- ヘッダーとナビゲーション(**未決**。ログアウトの導線もここに置く)
- 状態の表示: 読み込み中、AI の処理中(食事の推定、レポートの作成)、空の状態(記録ゼロ)、エラー、「まだ記録できません(プロフィールの設定が先)」の誘導
- ボタンの規則: 決定する操作だけ真っ黒、弱い操作はグレーの塗り、並びは「キャンセル、決定」(決定が右)、削除は左の別のセル
- 注記: 「医療上の指示ではない」、AI への送信の同意文、記録が不完全な日の但し書き
- グラフ 7 種: 体重、体脂肪率、睡眠、摂取カロリー、摂取 − 消費の差、栄養のレーダー、記録のカレンダー

## E. 作っていない・後で決める
- プライバシーと利用規約のページ(公開前。`docs/release-checklist.md`)
- ランディング(紹介ページ)。友人だけの運用なら不要
- ダークモード: 対応する場合は、方針を決める

## 優先順位の案
1. 共通の枠(D)を決める。ナビゲーションが全画面に効く
2. B1・B2・B5(使う時間が長く、グラフが多い)
3. A1〜A3(入口)
4. C1〜C8 は、ボタンの規則を渡して、同じ型で揃える
